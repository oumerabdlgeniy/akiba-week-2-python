## Mini Project: Simple Bank Account System

This project is a simple interactive bank account system developed using Python.

### Features

- Starts with an initial balance of 1000 Birr.
- Allows users to check their account balance.
- Allows users to deposit money.
- Allows users to withdraw money.
- Prevents zero and negative deposits.
- Checks whether sufficient balance is available before withdrawal.
- Provides a menu that continues until the user exits.
- Includes a three-attempt PIN verification system.

### Concepts Used

- Variables
- Conditional statements
- While loops
- Comparison and logical operators
- Input validation
- Counters

## How to Run the Programs

### 1. Install Python

Make sure Python 3 is installed on your computer.

Check the Python version:

```bash
python --version
```

### 2. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 3. Navigate to the Project Folder

```bash
cd akiba-week-2-python
```

### 4. Run a Python File

For example, to run the Even or Odd program:

```bash
python task_01_even_odd.py
```

To run another task, replace the filename with the desired Python file.

For example:

```bash
python task_03_prime_checker.py
```

To run the Bank Account mini project:

```bash
python mini_project_bank.py
```

**Note:** You can also run the Python files directly using Visual Studio Code.
